ВЫХОД ТС: АВТОСБОРКА ЧЕРЕЗ GITHUB ACTIONS
==========================================

ОДИН РАЗ (подготовка)
---------------------
0. Страховка: зайдите в репозиторий summary -> зелёная кнопка «Code» -> «Download ZIP».
   Сохраните архив. Если что-то пойдёт не так, этими файлами можно вернуть всё как было.

1. Распакуйте архив «пакет» (этот). Внутри: папки .github, scripts, data, archive, input
   и файлы index.html, data.json, drivers.json.

2. В репозитории нажмите «Add file» -> «Upload files».
   Перетащите в окно ВСЕ папки и файлы из пакета (папку .github тоже!).
   Файлы index.html, data.json, drivers.json заменят старые - это нормально.
   Файлы sw.js, manifest.json и иконки НЕ трогайте, они остаются.
   Внизу нажмите «Commit changes».
   (Если браузер не принимает папку .github - см. пункт 2б.)

2б. Если папка .github не загрузилась: «Add file» -> «Create new file», в поле имени введите
   .github/workflows/build.yml  (слэши создадут папки), вставьте туда текст из файла build.yml
   из пакета и нажмите Commit.

3. Разрешите роботу сохранять результат:
   Settings -> Actions -> General -> внизу «Workflow permissions» ->
   выберите «Read and write permissions» -> Save.

4. Проверка: откройте вкладку Actions. Если GitHub просит включить Actions -
   нажмите зелёную кнопку согласия.

КАЖДЫЙ ДЕНЬ
-----------
1. Откройте репозиторий в браузере (на телефоне тоже), зайдите в папку input.
2. «Add file» -> «Upload files». Загрузите свод и экспорт (два файла xlsx). Имена любые.
3. «Commit changes».
4. Вкладка Actions: появится запуск. Жёлтая точка = работает, зелёная галочка = готово (около минуты).
   Сайт обновится сам. Новый день автоматически попадёт в архив.
   Нажмите на запуск -> «Summary» - там коротко: сколько машин, сколько водителей без телефона.

ЕСЛИ КРАСНЫЙ КРЕСТИК
--------------------
Сделайте скриншот страницы запуска (там видна причина) и пришлите мне в чат.
Пока чините - работайте по-старому (присылаете мне файлы, я отдаю data.json и drivers.json).
Робот сам очищает input/ после ошибки, просто загрузите файлы заново после исправления.

КОГДА МЕНЯЕТСЯ ВАХТА MOBIL SERVICE
----------------------------------
Загрузите новый список вахты (xlsx «Вахта тізімі …») в папку input/ как обычно.
Робот распознает его сам и обновит data/mobil.json. Старые машины, которых нет в новом списке,
остаются. Свод и экспорт при этом загружать не обязательно.

КОГДА ПОЯВИЛИСЬ НОВЫЕ ВОДИТЕЛИ БЕЗ ТЕЛЕФОНА
------------------------------------------
Пришлите мне свежий файл «КБМ Водители» - я пересоберу data/contacts.json и пришлю его.
Сам файл КБМ в репозиторий НЕ загружайте (там зарплаты и данные всех сотрудников).

АРХИВ
-----
Хранится 365 дней в папке archive/ГГГГ-ММ-ДД. Вверху сайта - выбор даты.
Если загрузить файлы за прошлую дату - они попадут в архив, а на сайте останется самая свежая дата.
